# Terraform GCP Infrastructure

## Overview

Infrastructure as Code (IaC) project to provision a Google Kubernetes Engine (GKE) cluster using Terraform.

---

## Architecture

Terraform
   |
   v
Google Cloud Platform
   |
   +-- GKE Cluster
   |
   +-- Node Pool

---

## Technologies

- Terraform
- Google Cloud Platform (GCP)
- Google Kubernetes Engine (GKE)

---

## Resources Created

- GKE Cluster
- Node Pool
- Cluster Outputs

---

## Commands

### Initialize

```bash
terraform init
```

### Validate

```bash
terraform validate
```

### Plan

```bash
terraform plan
```

### Apply

```bash
terraform apply
```

### Destroy

```bash
terraform destroy
```
